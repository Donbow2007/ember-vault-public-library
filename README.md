# Ember Vault Public Library

This repository hosts unchanged source files used by the Ember Vault offline knowledge catalog when an authoritative publisher does not provide a dependable unattended download endpoint.

Files are distributed as GitHub Release assets so they do not inflate application source history. Every asset is accompanied by publisher, edition, provenance, distribution-status, byte-size, and SHA-256 metadata in [`manifest.json`](manifest.json).

## Important

- Inclusion does not convert military doctrine, food-safety guidance, or other reference material into professional advice.
- Each document remains attributable to its issuing organization and subject to notices inside that document.
- Military publications in the initial release state that they are approved for public release and that distribution is unlimited.
- Files are preserved without content changes. A new upstream edition must be reviewed and released as a new version rather than replacing an existing asset silently.
- The application should verify the full SHA-256 digest before indexing a download.

This repository contains reference publications, not executable software.
